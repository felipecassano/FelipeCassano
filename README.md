### 🚀 Featured Project

⚡ **[Energy Start — Regulatory Intelligence & AI Copilot](https://github.com/felipecassano/projeto-hackaton-ia)**
> Built during the **COPPE AI Hackathon 2026**. An end-to-end platform that monitors Brazil's Official Gazette (ANEEL, MME, CNPE) daily, classifies and summarizes regulatory changes using LLMs, cross-references rules against power plant operational profiles to trigger automated alerts, and provides a **RAG (Retrieval-Augmented Generation)** Copilot with verified official citations.
> - **Stack:** `TypeScript` · `NestJS` · `TypeORM` · `React` · `Python` · `PostgreSQL` · `Docker` · `AWS (Fargate / Bedrock / CDK)`
